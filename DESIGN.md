# Design

A filmmaker is preparing screening copies at a desktop in the same dim editing
room where they reviewed the finished movie. Warm charcoal avoids a bright
transition; quiet citron identifies primary actions and private recovery downloads.
Use the restrained palette and system type shared with the film workspace.

One page, two task tabs: Create copies / Check a leak. A setup column sits beside
live jobs and downloads. Thin separators, plain progress text and actual output
links carry hierarchy. No decorative images, card grid, gradients or animated hero.
Mobile stacks setup above results. Actions and errors use labels as well as color.
