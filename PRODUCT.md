# Watermark Studio

Register: product.

Independent creators need a private, understandable way to make individually
marked screening copies and later check a suspected leak. They should be able to
upload, choose count/size, download verified copies, and back up recovery data
without assembling scripts or API requests. Each creator operates their own Pod.

The tone is calm, plain and accurate. Processing, checking, failure and recovery
must be distinct. A matched copy is never described as an identified person.
Private recovery files should be prominent and clearly separated from the movies
people share. Public state must never expose their contents.

Avoid an ornamental dashboard, fake sample footage, overconfident protection
claims, deeply nested settings and developer terminology in everyday controls.
Use keyboard-accessible forms, visible focus, sufficient contrast, inline errors
and a layout that stacks on narrow screens. Keep the requested workflow small.
